  # Brisa — Gestão de Estoque                                                                        
                                                                                                     
  Sistema web para controle de estoque, vendas e resultados financeiros de uma loja de perfumes de ambiente.           
                                                                                                     
  ![React](https://img.shields.io/badge/React-18-61DAFB?logo=react) ![Firebase](https://img.shields.io/badge/Firebase-Hosting-FFCA28?logo=firebase) ![Vite](https://img.shields.io/badge/Vite-5-646CFF?logo=vite)                                                                                      
                                                                                                     
  O Brisa foi desenvolvido para simplificar a administração de uma loja de perfumes. A aplicação centraliza o controle de produtos, movimentações de estoque, vendas, lucros e despesas em uma interface responsiva.                                                                                                           
                                                                                                     
  ## Funcionalidades                                                                                 
                                                                                                     
  - Cadastro e edição de produtos                                                                    
  - Registro de entradas e saídas                                                                    
  - Controle da quantidade disponível                                                                
  - Registro e histórico de vendas                                                                   
  - Cálculo de faturamento e lucro                                                                   
  - Balanço entre entradas e despesas                                                                
  - Gráficos e indicadores financeiros                                                               
  - Autenticação de administradores                                                                  
  - Sincronização em tempo real                                                                      
  - Interface adaptada para celular e computador
